# Thaneesan Siventhirarajah — GitHub Pages Portfolio

## Upload
1. Create a public repository named `thaneesan99.github.io`.
2. Upload everything in this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Open `https://thaneesan99.github.io/`.

## Easy editing
- Home: `index.html`
- Research: `research.html`
- Projects: `projects.html`
- About: `about.html`
- Publications: `publications.html`
- Contact: `contact.html`
- Colours/layout: `assets/style.css`
- Gallery popup: `assets/site.js`
- Profile image: `assets/profile-photo.png`

Replace placeholder `example.com` links and sample gallery images with your real content. External links are configured to open in a new tab.
